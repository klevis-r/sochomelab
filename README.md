# SOC Home Lab

A home SOC lab I'm building to learn how networks are attacked, defended and monitored, so that I can work towards a SOC analyst apprenticeship.

Every lab and step is documented below with what I did, what I've broken, how I've diagnosed it, and evidence.

## Labs

| # | Lab | Skills |
|---|-----|--------|
| 01 | [Building a segmented network with OPNsense](lab-01/README.md) | Virtual networking, firewall interfaces, DHCP, troubleshooting with tcpdump |
| 02 | [Adding a server and fixing a DHCP fault](lab-02/README.md) | Packet capture analysis, root-cause analysis, Dnsmasq |
| 03 | [First firewall rules: segmentation and logging](lab-03/README.md) | Firewall rule order, routing tables, NTP/time issues, detection using firewall logs |
